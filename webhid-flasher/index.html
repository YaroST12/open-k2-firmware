Open-K2 WebHID Flasher

Flash firmware to a WITRN K2 straight from the browser. Chromium only (Chrome/Edge), served over https.
not connected
Mode— Firmware— Git—
Accepts a .k2 container or a raw app .bin (auto-wrapped, like tools/k2_flasher.py). If the K2 runs the app, it is sent into the bootloader first (DFU_ENTER); if it is already in DFU (hold MINUS while plugging in), it is flashed directly. Full erase + write + read-back verify + commit marker, then reboot.
