Open-K2 WebHID Flasher

Flash firmware to a WITRN K2 straight from the browser. Chromium only (Chrome/Edge), served over https.

Mode— Firmware— Git—
Accepts a .k2 container or a raw app .bin (auto-wrapped, like tools/k2_flasher.py). If the K2 runs the app, it is sent into the bootloader first (DFU_ENTER); if it is already in DFU (hold MINUS while plugging in), it is flashed directly. Full erase + write + read-back verify + commit marker, then reboot.
Download recovery .k2
Also:
Reads the bootloader and the application area twice, compares both passes, and offers a recovery .k2 container of the application code (the same read as tools/k2_flasher.py backup). To restore later, pick the backup you saved (K2_RECOVERY_*.k2) in the Flash firmware row above: it is flashed like any firmware. The K2's stored data (the sessions and settings volume, the native storage with e-marker records) is saved in flash.bin but not restored: the flasher never writes it back, and flashing the recovery container leaves it where it is.
