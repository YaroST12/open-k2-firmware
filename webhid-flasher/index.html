Every flash starts with a full backup of the K2 (bootloader, application and device storage), saved as one ZIP. It is the only way back to the firmware that is on the K2 now.
No backup will be made. Flashing erases the firmware that is on this K2 now, and without a backup it cannot be brought back.
Accepts a .k2 container, a raw app .bin (auto-wrapped, like tools/k2_flasher.py) or a K2_BACKUP_*.zip (its K2_RECOVERY_*.k2 is flashed). If the K2 runs the app, it is sent into the bootloader first (DFU_ENTER); if it is already in DFU (hold MINUS while plugging in), it is flashed directly. With Back up this K2 first ticked the full backup runs before the erase. Full erase + write + read-back verify + commit marker, then reboot.

Reads the whole 1 MB twice (bootloader, application, device storage) and compares both passes. The result is one ZIP, K2_BACKUP_<version>_<UTC time>.zip, holding K2_RECOVERY_*.k2, flash.bin, app.bin, bootloader.bin, native_nvram.bin and manifest.json. Keep that file. To restore later, pick the ZIP (or the K2_RECOVERY_*.k2 in it) in the Flash firmware row above: the recovery container is flashed like any firmware. The K2's stored data (the sessions and settings volume, the native storage with e-marker records) is saved in flash.bin but not written back: the flasher never writes it, and flashing the recovery container leaves it where it is. If the bootloader refuses to serve the device storage, the backup says so and is marked partial.
