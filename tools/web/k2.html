Start the charger test?

OTHER PORT FREE? A device on the other port can be damaged. Unplug it.

The K2 becomes an active sink and asks the charger for every level it offers in the chosen units: each PD voltage, the PPS / AVS steps, EPR levels up to the K2's monitor ceiling, and the QC and vendor fast-charge modes. The K2's output follows every level. Disconnect any phone, laptop or other load from the output first.

The K2 runs its own START checks before anything changes (charger present, no load, the cable guard for a spoofed identity) and can still refuse; the reason shows here. Cancel stops the run like BACK on the K2.
